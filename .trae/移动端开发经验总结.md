# 移动端开发经验总结文档

## 一、文档概述

本文档总结了移动端日历应用开发过程中遇到的问题、解决方案和最佳实践，旨在为后续开发提供参考和指导。

## 二、核心问题与解决方案

### 1. 数据共享问题

#### 问题描述
添加的任务不能显示到页面，任务数据未在不同组件间共享。

#### 根本原因
组件间数据隔离，缺乏全局状态管理机制。

#### 解决方案
创建独立的Context（TasksContext、NotesContext、PointsContext、FamilyContext）实现数据共享：

```javascript
// 创建Context
const TasksContext = createContext();

// 创建Provider
export const TasksProvider = ({ children }) => {
  const [tasks, setTasks] = useState([]);
  
  const addTask = (task) => {
    setTasks([...tasks, { ...task, id: Date.now().toString() }]);
  };
  
  const toggleTask = (id) => {
    setTasks(tasks.map(task => 
      task.id === id ? { ...task, completed: !task.completed } : task
    ));
  };
  
  const deleteTask = (id) => {
    setTasks(tasks.filter(task => task.id !== id));
  };
  
  return (
    <TasksContext.Provider value={{ tasks, addTask, toggleTask, deleteTask }}>
      {children}
    </TasksContext.Provider>
  );
};

// 使用Context
export const useTasks = () => {
  const context = useContext(TasksContext);
  if (!context) {
    throw new Error('useTasks must be used within a TasksProvider');
  }
  return context;
};
```

#### 最佳实践
- 为每个功能模块创建独立的Context
- 使用自定义Hook（如useTasks）简化Context使用
- 在App.js顶层包裹所有Provider

### 3. 积分系统重构

#### 问题描述
原积分系统无成员概念，有pending状态，不符合实际需求。

#### 根本原因
积分系统设计过于复杂，不符合家庭场景。

#### 解决方案
重新设计为基于成员的积分系统：

```javascript
// PointsContext.js
const initialMembers = [
  { id: '1', name: '爸爸', avatar: '爸', basePoints: 100, currentPoints: 0 },
  { id: '2', name: '妈妈', avatar: '妈', basePoints: 100, currentPoints: 0 },
  { id: '3', name: '孩子', avatar: '孩', basePoints: 100, currentPoints: 0 },
];

const [members, setMembers] = useState(initialMembers);
const [checkInTasks, setCheckInTasks] = useState([]);

const calculateTaskPoints = (task) => {
  const completedDatesInPeriod = getCompletedDatesInPeriod(task);
  const completedCount = completedDatesInPeriod.length;
  
  if (task.frequency === 'daily') {
    return completedCount > 0 ? task.totalPoints : 0;
  } else if (task.frequency === 'weekly') {
    return Math.floor((completedCount / 7) * task.totalPoints);
  } else if (task.frequency === 'monthly') {
    const today = new Date();
    const daysInMonth = new Date(today.getFullYear(), today.getMonth() + 1, 0).getDate();
    return Math.floor((completedCount / daysInMonth) * task.totalPoints);
  }
  
  return 0;
};
```

#### 关键设计点
- 积分基于成员，每个成员独立计算
- 任务完成后直接加分，无需审批
- 支持不同周期任务（每日、每周、每月）
- 实现连续打卡功能

#### 最佳实践
- 积分计算逻辑集中管理
- 使用basePoints和currentPoints区分历史分和当前分
- 按比例计算不同周期任务的积分

### 4. Weekly/Monthly任务积分计算

#### 问题描述
Weekly和Monthly任务直接给总分，不符合实际需求。

#### 解决方案
按已完成天数比例计算积分：

```javascript
const getCompletedDatesInPeriod = (task) => {
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  
  let startDate;
  if (task.frequency === 'weekly') {
    const dayOfWeek = today.getDay();
    startDate = new Date(today);
    startDate.setDate(today.getDate() - dayOfWeek);
    startDate.setHours(0, 0, 0, 0);
  } else if (task.frequency === 'monthly') {
    startDate = new Date(today.getFullYear(), today.getMonth(), 1);
  }
  
  return task.completedDates.filter(date => {
    const completedDate = new Date(date);
    completedDate.setHours(0, 0, 0, 0);
    return completedDate >= startDate && completedDate <= today;
  });
};
```

#### 最佳实践
- 使用completedDates数组记录打卡日期
- 根据任务频率动态计算周期范围
- 使用Date对象进行日期比较

### 8. currentPoints更新问题

#### 问题描述
第一次点击Check In current不变化，但是Today's Progress会变化。

#### 根本原因
状态更新异步，setMembers在setCheckInTasks外部调用时使用了旧数据。

#### 解决方案
将状态更新移到setCheckInTasks内部：

```javascript
const toggleTaskCheckIn = (taskId) => {
  setCheckInTasks(prev => {
    const updatedTasks = prev.map(task => {
      if (task.id !== taskId) return task;
      
      const today = new Date().toDateString();
      const isCompletedToday = task.completedDates.some(
        date => new Date(date).toDateString() === today
      );
      
      if (isCompletedToday) {
        return {
          ...task,
          completedDates: task.completedDates.filter(
            date => new Date(date).toDateString() !== today
          )
        };
      } else {
        return {
          ...task,
          completedDates: [...task.completedDates, new Date().toISOString()]
        };
      }
    });
    
    // 使用updatedTasks计算currentPoints
    const memberTasks = updatedTasks.filter(t => t.memberId === task.memberId);
    const currentPoints = memberTasks.reduce((sum, t) => sum + calculateTaskPoints(t), 0);
    
    setMembers(prevMembers => {
      return prevMembers.map(m => {
        if (m.id !== task.memberId) return m;
        return { ...m, currentPoints: currentPoints };
      });
    });
    
    return updatedTasks;
  });
};
```

#### 最佳实践
- 理解React状态更新的异步特性
- 在setState回调中使用最新状态
- 避免依赖外部状态

### 9. 删除任务后currentPoints未重新计算

#### 问题描述
删除任务后，成员的currentPoints没有更新。

#### 解决方案
在deleteCheckInTask中添加重新计算逻辑：

```javascript
const deleteCheckInTask = (taskId) => {
  const taskToDelete = checkInTasks.find(t => t.id === taskId);
  if (!taskToDelete) return;
  
  setCheckInTasks(prev => {
    const updatedTasks = prev.filter(task => task.id !== taskId);
    
    const memberTasks = updatedTasks.filter(t => t.memberId === taskToDelete.memberId);
    const currentPoints = memberTasks.reduce((sum, t) => sum + calculateTaskPoints(t), 0);
    
    setMembers(prevMembers => {
      return prevMembers.map(m => {
        if (m.id !== taskToDelete.memberId) return m;
        return { ...m, currentPoints: currentPoints };
      });
    });
    
    return updatedTasks;
  });
};
```

#### 最佳实践
- 删除操作后立即重新计算相关数据
- 保持数据一致性
- 处理边界情况（任务不存在）

## 四、状态管理最佳实践

### 1. Context设计原则

- 单一职责：每个Context只管理一个功能模块
- 数据集中：相关数据放在同一个Context中
- 提供便捷方法：封装常用操作为方法
- 使用自定义Hook：简化Context使用

### 2. 状态更新模式

```javascript
// 错误示例
const toggleTask = (id) => {
  const task = tasks.find(t => t.id === id);
  task.completed = !task.completed;
  setTasks([...tasks]);
};

// 正确示例
const toggleTask = (id) => {
  setTasks(prev => prev.map(task => 
    task.id === id ? { ...task, completed: !task.completed } : task
  ));
};
```

### 3. 异步状态更新

```javascript
// 错误示例
const updatePoints = (taskId) => {
  toggleTask(taskId);
  const newPoints = calculatePoints();  // 使用的是旧数据
  setPoints(newPoints);
};

// 正确示例
const updatePoints = (taskId) => {
  setTasks(prev => {
    const updated = prev.map(task => 
      task.id === taskId ? { ...task, completed: !task.completed } : task
    );
    
    const newPoints = calculatePoints(updated);  // 使用新数据
    setPoints(newPoints);
    
    return updated;
  });
};
```

## 九、常见错误及解决

### 1. TypeError: Cannot read property 'xxx' of undefined

**原因**：对象为null或undefined

**解决**：
```javascript
const member = members.find(m => m.id === memberId);
if (!member) return;  // 添加检查
```

### 2. Maximum update depth exceeded

**原因**：无限循环渲染

**解决**：
```javascript
// 错误示例
useEffect(() => {
  setCount(count + 1);
}, [count]);

// 正确示例
useEffect(() => {
  setCount(prev => prev + 1);
}, []);
```

### 3. Warning: Each child in a list should have a unique "key" prop

**原因**：列表项缺少key

**解决**：

1. **数据共享**：使用Context API实现跨组件数据共享
2. **状态管理**：理解React状态更新的异步特性
3. **UI组件**：熟悉React Native Paper组件的使用
4. **样式设计**：合理使用Flexbox布局
5. **性能优化**：避免不必要的渲染
6. **调试技巧**：善用开发工具
