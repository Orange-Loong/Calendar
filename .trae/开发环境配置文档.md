# 电子日历开发环境配置文档

## 一、文档概述

本文档详细说明了电子日历系统的开发环境配置步骤，包括Web端、移动端和后端的环境搭建、依赖安装和项目运行等。文档旨在帮助开发团队快速搭建开发环境，确保开发环境的一致性和可靠性。

## 二、开发环境基本要求

| 工具/软件 | 版本 | 用途 |
|-----------|------|------|
| **Node.js** | 20.x 或更高 | JavaScript运行环境 |
| **npm** | 10.x 或更高 | 包管理器 |
| **Git** | 2.x 或更高 | 版本控制 |
| **MongoDB** | 6.x 或更高 | 数据库 |
| **VS Code** | 最新版本 | 代码编辑器 |
| **Expo CLI** | 最新版本 | React Native开发工具 |
| **Postman** | 最新版本 | API测试工具 |

## 三、Web端开发环境配置

### 1. 克隆代码仓库

```bash
git clone <repository-url>
cd calendar/web
```

### 2. 安装依赖

```bash
npm install
```

### 3. 运行开发服务器

```bash
npm run dev
```

### 4. 访问应用

打开浏览器访问：`http://localhost:5173`

### 5. 构建生产版本

```bash
npm run build
```

### 6. 预览生产版本

```bash
npm run preview
```

## 四、移动端开发环境配置

### 1. 克隆代码仓库


## 五、后端开发环境配置

### 1. 克隆代码仓库

```bash
git clone <repository-url>
cd calendar/backend
```

### 2. 初始化项目

```bash
npm init -y
```

### 3. 安装依赖

```bash
npm install express mongoose jsonwebtoken bcrypt cors dotenv
npm install -D nodemon
```

### 4. 创建环境配置文件

创建 `.env` 文件，添加以下内容：

```env
# 服务器配置
PORT=3000
NODE_ENV=development

# MongoDB配置
MONGODB_URI=mongodb://localhost:27017/digital-calendar

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=7d

# FCM配置（可选，用于推送通知）
FCM_SERVER_KEY=your-fcm-server-key
```

### 5. 运行开发服务器

```bash
npm run dev
```

### 6. 构建生产版本

```bash
npm run build
```

### 7. 运行生产版本

```bash
npm start
```

## 六、数据库配置

### 1. 安装MongoDB

#### macOS

```bash
brew tap mongodb/brew
brew install mongodb-community@6.3
brew services start mongodb-community@6.3
```

#### Windows

- 下载MongoDB安装包：[MongoDB Download Center](https://www.mongodb.com/try/download/community)
- 运行安装包，按照向导安装
- 确保MongoDB服务已启动

#### Linux

```bash
wget -qO - https://www.mongodb.org/static/pgp/server-6.3.asc | sudo apt-key add -
sudo apt-get install gnupg
wget -qO - https://www.mongodb.org/static/pgp/server-6.3.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.3 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.3.list
sudo apt-get update
sudo apt-get install -y mongodb-org
sudo systemctl start mongod
sudo systemctl enable mongod
```

### 2. 连接MongoDB

使用MongoDB Compass或mongosh连接数据库：

```bash
mongosh mongodb://localhost:27017
```

### 3. 创建数据库

```bash
use digital-calendar
```

## 八、常见问题及解决方案

### 1. Node.js版本不兼容

**问题**：安装依赖时出现Node.js版本不兼容错误

**解决方案**：
- 使用nvm（Node Version Manager）管理Node.js版本
- 安装推荐的Node.js版本（20.x 或更高）

```bash
# 安装nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash

# 安装Node.js 20.x
nvm install 20
nvm use 20
```

### 2. 端口被占用

**问题**：运行开发服务器时出现端口被占用错误

**解决方案**：
- 关闭占用端口的进程
- 修改配置文件中的端口号

```bash
# 查找占用端口的进程
lsof -i :5173

# 终止进程
kill -9 <PID>
```

### 3. MongoDB连接失败

**问题**：后端无法连接到MongoDB数据库

**解决方案**：
- 确保MongoDB服务已启动
- 检查MongoDB连接字符串是否正确
- 检查防火墙设置

```bash
# 检查MongoDB服务状态
sudo systemctl status mongod

# 启动MongoDB服务
sudo systemctl start mongod
```

### 4. Expo运行时错误

**问题**：运行Expo开发服务器时出现错误

**解决方案**：
- 清除Expo缓存
- 更新Expo CLI和依赖
- 检查网络连接

```bash
# 清除Expo缓存
expo start --clear

# 更新Expo CLI
npm install -g expo-cli

# 更新依赖
npm install -g expo-cli
npx expo install --fix
```

### 5. 依赖冲突

**问题**：安装依赖时出现依赖冲突错误

**解决方案**：
- 使用npm install --legacy-peer-deps安装依赖
- 更新依赖版本
- 删除node_modules和package-lock.json，重新安装依赖

```bash
# 使用legacy-peer-deps安装依赖
npm install --legacy-peer-deps

# 重新安装依赖
rm -rf node_modules package-lock.json
npm install
```

## 九、开发流程

### 1. 分支管理

- **main**：主分支，稳定版本
- **develop**：开发分支，集成所有功能
- **feature/**：功能分支，开发新功能
- **hotfix/**：热修复分支，修复生产环境问题

### 2. 代码提交规范

- 使用Conventional Commits规范
- 提交信息格式：`<type>(<scope>): <description>`

**类型**：
- feat：新功能
- fix：修复bug
- docs：文档更新
- style：代码格式调整
- refactor：代码重构
- test：测试代码
- chore：构建过程或辅助工具的变动

**示例**：
```
feat(web): 添加日历月视图
fix(mobile): 修复任务列表渲染问题
docs: 更新开发环境配置文档
```

### 3. 代码审查

- 所有代码变更必须通过代码审查
- 使用Pull Request进行代码审查
- 至少需要1个审查者批准才能合并
