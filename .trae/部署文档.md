# 电子日历部署文档

## 一、文档概述

本文档详细说明了电子日历系统的生产环境部署步骤，包括Web端、移动端和后端的部署架构、配置管理、监控日志、备份恢复等。文档旨在帮助运维人员或开发人员快速部署和管理电子日历系统，确保系统的可靠性、安全性和高性能。

## 三、部署前准备

### 1. 服务器准备

- 购买或租赁云服务器（推荐AWS、阿里云、腾讯云等）
- 配置服务器网络和防火墙
- 安装操作系统和必要的软件
- 配置SSH密钥登录

### 2. 域名和SSL证书

- 注册域名并解析到服务器IP
- 申请SSL证书（推荐Let's Encrypt免费证书）
- 配置HTTPS访问

### 3. 环境变量配置

创建`.env`配置文件，包含以下环境变量：

```env
# 服务器配置
PORT=3000
NODE_ENV=production

# MongoDB配置
MONGODB_URI=mongodb://username:password@mongodb-server:27017/digital-calendar?replicaSet=rs0

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=7d

# FCM配置
FCM_SERVER_KEY=your-fcm-server-key

# 日志配置
LOG_LEVEL=info

# CORS配置
ALLOWED_ORIGINS=https://your-domain.com,https://www.your-domain.com
```

## 四、Web端部署

### 1. 构建生产版本

```bash
# 进入Web目录
cd calendar/web

# 安装依赖
npm install

# 构建生产版本
npm run build
```

### 2. 部署到Nginx

#### 2.1 安装Nginx

```bash
# 安装Nginx
sudo apt update
sudo apt install nginx

# 启动Nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

#### 2.2 配置Nginx

创建Nginx配置文件 `/etc/nginx/sites-available/digital-calendar-web`：

```nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    
    # SSL配置
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;
    
    # 根目录配置
    root /var/www/digital-calendar-web/dist;
    index index.html;
    
    # 路由配置
    location / {
        try_files $uri $uri/ /index.html;
        expires 1d;
    }
    
    # API代理配置
    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 7d;
        add_header Cache-Control "public, max-age=604800";
    }
    
    # 日志配置
    access_log /var/log/nginx/digital-calendar-web-access.log;
    error_log /var/log/nginx/digital-calendar-web-error.log;
}
```

#### 2.3 激活配置并重启Nginx

```bash
# 创建符号链接
sudo ln -s /etc/nginx/sites-available/digital-calendar-web /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

#### 2.4 部署构建文件

```bash
# 创建部署目录
sudo mkdir -p /var/www/digital-calendar-web

# 复制构建文件
sudo cp -r dist/* /var/www/digital-calendar-web/

# 设置权限
sudo chown -R www-data:www-data /var/www/digital-calendar-web
sudo chmod -R 755 /var/www/digital-calendar-web
```

## 五、后端部署

### 1. 安装Node.js和PM2

```bash
# 安装Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装PM2
sudo npm install -g pm2
```

### 2. 部署后端代码

```bash
# 创建部署目录
sudo mkdir -p /var/www/digital-calendar-backend

# 复制后端代码
sudo cp -r backend/* /var/www/digital-calendar-backend/

# 进入后端目录
cd /var/www/digital-calendar-backend

# 安装依赖
npm install --production

# 设置环境变量
cp .env.example .env
# 编辑.env文件，配置环境变量
```

### 3. 使用PM2管理进程

```bash
# 启动后端服务
npm start

# 或使用PM2启动
npm install -g pm2
npm run dev-pm2

# 配置PM2自动启动
sudo pm2 startup systemd
sudo pm2 save

# 查看PM2进程状态
npm run pm2-status

# 重启后端服务
npm run pm2-restart

# 停止后端服务
npm run pm2-stop
```

### 4. 配置Nginx反向代理

在Nginx配置文件中添加API代理配置（参考Web端Nginx配置）。

## 六、数据库部署

### 1. 安装MongoDB

```bash
# 导入MongoDB GPG密钥
wget -qO - https://www.mongodb.org/static/pgp/server-6.3.asc | sudo apt-key add -

# 添加MongoDB源
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.3 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.3.list

# 安装MongoDB
sudo apt update
sudo apt install -y mongodb-org

# 启动MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod

# 查看MongoDB状态
sudo systemctl status mongod
```

### 2. 配置MongoDB

#### 2.1 连接MongoDB

```bash
mongosh
```

#### 2.2 创建管理员用户

```javascript
use admin

// 创建管理员用户
db.createUser({
  user: "admin",
  pwd: "your-admin-password",
  roles: [{ role: "root", db: "admin" }]
})

// 启用认证
// 编辑 /etc/mongod.conf，添加以下配置：
# security:
#   authorization: enabled

// 重启MongoDB
sudo systemctl restart mongod
```

#### 2.3 创建应用用户和数据库

```javascript
// 使用管理员用户登录
mongosh -u admin -p your-admin-password --authenticationDatabase admin

// 创建数据库
use digital-calendar

// 创建应用用户
db.createUser({
  user: "app-user",
  pwd: "your-app-password",
  roles: [
    { role: "readWrite", db: "digital-calendar" },
    { role: "dbAdmin", db: "digital-calendar" }
  ]
})
```

#### 2.4 配置副本集（可选，用于高可用性）

```javascript
// 初始化副本集
rs.initiate()

// 添加副本集成员
rs.add("mongodb-server-2:27017")
rs.add("mongodb-server-3:27017")

// 查看副本集状态
rs.status()
```

## 十、备份和恢复

### 1. 数据备份

#### 1.1 MongoDB备份

```bash
# 全量备份
mongodump --uri "mongodb://username:password@mongodb-server:27017/digital-calendar" --out /backup/mongodb/$(date +%Y%m%d)

# 增量备份（使用Oplog）
mongodump --uri "mongodb://username:password@mongodb-server:27017/digital-calendar" --oplog --out /backup/mongodb/$(date +%Y%m%d)-oplog

# 定时备份，添加到crontab
0 2 * * * mongodump --uri "mongodb://username:password@mongodb-server:27017/digital-calendar" --out /backup/mongodb/$(date +%Y%m%d)
```

#### 1.2 应用代码备份

```bash
# 使用rsync备份应用代码
rsync -avz /var/www/digital-calendar-* /backup/code/

# 定时备份，添加到crontab
0 3 * * * rsync -avz /var/www/digital-calendar-* /backup/code/
```

### 2. 数据恢复

#### 2.1 MongoDB恢复

```bash
# 全量恢复
mongorestore --uri "mongodb://username:password@mongodb-server:27017/digital-calendar" /backup/mongodb/20260112

# 增量恢复（使用Oplog）
mongorestore --uri "mongodb://username:password@mongodb-server:27017/digital-calendar" --oplogReplay /backup/mongodb/20260112-oplog
```

#### 2.2 应用代码恢复

```bash
# 恢复应用代码
rsync -avz /backup/code/digital-calendar-web/ /var/www/digital-calendar-web/
rsync -avz /backup/code/digital-calendar-backend/ /var/www/digital-calendar-backend/

# 重启服务
sudo systemctl restart nginx
npm run pm2-restart
```

## 十一、常见问题和解决方案

### 1. Nginx启动失败

**问题**：Nginx启动失败，报错"nginx: [emerg] invalid number of arguments in "listen" directive"

**解决方案**：
- 检查Nginx配置文件中的listen指令
- 确保端口号正确，没有语法错误
- 运行`nginx -t`检查配置文件

### 2. 后端服务无法连接数据库

**问题**：后端服务启动失败，报错"MongoDB connection error"

**解决方案**：
- 检查MongoDB服务是否启动
- 检查数据库连接字符串是否正确
- 检查数据库用户权限
- 检查防火墙设置

### 3. API请求返回500错误

**问题**：API请求返回500 Internal Server Error

**解决方案**：
- 查看后端日志，定位错误原因
- 检查数据库连接
- 检查环境变量配置
- 检查代码逻辑

### 4. 移动端应用无法访问API

**问题**：移动端应用无法访问后端API，报错"Network Error"

**解决方案**：
- 检查API地址是否正确
- 检查服务器防火墙设置
- 检查CORS配置
- 检查SSL证书是否有效

### 5. 数据库性能问题

**问题**：数据库查询缓慢，影响应用性能

**解决方案**：
- 为频繁查询的字段创建索引
- 优化查询语句
- 增加数据库服务器资源
- 考虑使用缓存

## 十二、系统升级

### 1. 升级步骤

1. **备份数据**：备份数据库和配置文件
2. **测试升级**：在测试环境中测试升级
3. **部署新版本**：

   - 再部署Web端应用

4. **验证升级**：检查系统功能是否正常
5. **回滚策略**：如果升级失败，准备回滚方案

- 升级前编写详细的升级文档

## 十三、安全管理

### 1. 服务器安全

- 定期更新操作系统和软件
- 配置防火墙，只开放必要端口
- 使用SSH密钥登录，禁用密码登录

- 定期更新依赖包

- 使用JWT进行身份认证

### 3. 数据安全

- 加密存储敏感数据
- 定期备份数据
- 限制数据库访问权限
- 实施数据访问日志
